NMB HOLDINGS LIMITED — DOMAIN READY
Target: https://nmbholdings.co.ke

1. Register/confirm the domain.
2. Connect it to your web host via DNS.
3. Upload all files in this package to public_html (or your host's web root).
4. Enable SSL/HTTPS.
5. Test the homepage, robots.txt and sitemap.xml.

This package prepares the website for the domain; it does not itself register the domain or change DNS records.
